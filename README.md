# 川崎ECCトレーニングサイト CCF計測器

心肺蘇生トレーニングで、CCF と胸骨圧迫の中断時間を計測する Web アプリです。

CCF は chest compression fraction（胸骨圧迫比率）の略です。

ブラウザだけで動き、インストールは要りません。

公開ページ: https://keiimai.github.io/kwskCCF/

> 教育・訓練用のツールです。
>
> 実際の患者の診療や臨床判断には使わないでください。
>
> 計測結果の正確さは保証しません。

## 使い方

1. 心停止を認識した瞬間に、下の赤い **心停止認識** ボタンを押します。
   - ここが計測の起点です。
2. 同じ場所のボタンが **胸骨圧迫開始** に変わります。
   - 胸骨圧迫が始まったら押します。
3. 中断したら **胸骨圧迫中断** を押し、再開したらまた **胸骨圧迫開始** を押します。
4. 初めて除細動したら、胸骨圧迫ボタンの右の **初回除細動** を押します。
   - ボタンには、心停止認識からの経過時間が出ます。
   - 1 分を過ぎると、ボタンが赤になります。
   - 1 回押すと、ボタンは消えます。
5. ROSC または蘇生中止のときは、**終了（ROSC・蘇生中止）** を押します。
   - 1 回押すと、その時点で計測が終わります。
6. 終了すると、下に **結果のQR** と **結果を共有** が出ます。
   - 大きな画面で結果を見せるときに使います（下の説明を見てください）。
7. **リセット** で、すべて消去します。
8. 見出しの **QR** ボタンを押すと、このページを開く QR コードが画面いっぱいに出ます。
   - どこかを押すと閉じます。

心停止認識、初回除細動、終了は、それぞれ 1 回だけです。

### 大きな画面で結果を見せるとき

- 終了したスマホで **結果のQR** を押し、iPad などのカメラで読み取ります。
  - 大きな画面向けの結果ページが開きます。
- Mac へは、**結果を共有** から AirDrop で送れます。
- Windows の PC へは、**結果を共有** からメールや LINE などでリンクを送ります。
- 結果はリンクの中にだけ入っていて、サーバーには送られません。
- スマホごとに別の結果になるので、何人が同時に使っても混ざりません。
- 結果ページの **一覧** で、その端末で開いた結果を並べて比べられます。
  - 一覧はその端末の中にだけ残り、**一覧を消去** で消せます。

### 電波のない所で使うとき

- 一度、電波のある所でこのページを開いておきます。
- そのあとは、電波がなくても開けます。
- 結果を見せる iPad や PC でも、一度開いておくと、電波がなくても結果ページが開けます。
- ホーム画面に追加すると、アプリのようにアイコンから開けます。

### 画面の見方

- **上の帯**：今の状態です。
  - 初回胸骨圧迫の前と中断中は秒数を数え、10 秒を超えると赤になります。
- **CCF と判定**：80% 以上は良好、60〜79% は許容、60% 未満は不可です。
- **時間**：心停止時間と、胸骨圧迫時間です。
- **ログ**：初回胸骨圧迫までの時間、初回除細動までの時間、すべての中断を表示します。
  - 中断は時系列で並べ、10 秒を超えたものを赤で示します。
  - 初回除細動までは、1 分以内なら緑、1 分を超えたら赤で示します。

計算方法と判定の詳細は [docs/spec.md](docs/spec.md) にあります。

QRコードは株式会社デンソーウェーブの登録商標です。
